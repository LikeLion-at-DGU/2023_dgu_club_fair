# 동국대학교 2023 동아리 박람회 웹사이트 🏫

동국대학교 학생들을 위한 동아리 박람회 정보 제공 웹사이트입니다. 캐릭터 "김토끼"와 "고끼리"와 함께 동아리를 탐색해보세요!

## 📖 프로젝트 소개

2023년 3월 9일-10일 양일간 진행된 동국대학교 동아리 박람회를 위해 제작된 웹사이트입니다. 학생들이 교내 동아리 정보를 쉽게 찾아보고, 동아리 부스 위치를 확인할 수 있도록 도와주는 종합 안내 플랫폼입니다.

## ✨ 주요 기능

### 🎯 메인 페이지
- 캐릭터 스토리텔링을 통한 동아리 박람회 소개
- 스크롤 인터랙션으로 구현된 몰입감 있는 스토리 전개
- 김토끼와 고끼리의 동아리 탐험 여정

### 🔍 동아리 소개 페이지
- **카테고리별 동아리 탐색**: IT, 문화·예술·공연, 봉사·사회활동, 학술·교양, 창업·취업, 체육, 친목
- **동아리 카드 뷰**: 각 동아리의 기본 정보와 이미지 제공
- **실시간 데이터**: Firebase를 통한 동적 동아리 정보 관리

### 🏛️ 동아리 부스 안내
- **인터랙티브 캠퍼스 맵**: 동아리 부스 위치 시각화
- **일자별 부스 배치**: 3월 9일, 10일 각각의 부스 배치도
- **부스 번호 및 동아리명 매칭**: 쉬운 부스 찾기 기능

### 🎭 공연 타임테이블
- **실시간 공연 스케줄**: 현재 진행 중인 공연 하이라이트
- **동아리별 공연 정보**: 로고, 시간, 공연 내용
- **일자별 스케줄 관리**: 박람회 양일 간의 공연 일정

### 🎮 동아리 추천 테스트
- 개인 성향에 맞는 동아리 추천 시스템
- 외부 테스트 페이지 연동

### ℹ️ 소개 페이지
- 제작팀 소개 (동국대학교 멋쟁이사자처럼)
- 협력 단체 정보 (동아리연합회, 동국대 알리미)
- 프로젝트 제작 배경 및 목적

## 🎨 디자인 특징

- **따뜻한 브라운 톤**: 동국대학교 정체성을 반영한 컬러 팔레트
- **캐릭터 중심 디자인**: 친근한 토끼 캐릭터들로 접근성 향상
- **반응형 웹 디자인**: 모바일과 데스크톱 모든 환경에서 최적화
- **부드러운 애니메이션**: 자연스러운 사용자 경험 제공

## 🛠️ 기술 스택

- **Frontend**: React 18, React Router DOM
- **Styling**: Styled Components, Material-UI
- **Database**: Firebase Firestore
- **Authentication**: Firebase Auth
- **Hosting**: Netlify
- **Icons**: FontAwesome

## 👥 제작팀

**동국대학교 멋쟁이사자처럼**
- 누구나 자신의 아이디어를 구현할 수 있는 IT 창업동아리
- 100만 이상 유저가 사용한 다양한 서비스 개발 경험

## 🤝 협력 단체

- **동아리연합회**: 동아리 정보 제공 및 박람회 기획
- **동국대 알리미**: 홍보 및 학생 소통 지원

## 🎯 프로젝트 목적

동아리 박람회를 맞아 학우분들께서 교내 동아리의 정보를 보다 쉽게 살펴볼 수 있는 디지털 플랫폼을 제공하여, 학생들의 동아리 선택과 캠퍼스 라이프 향상에 기여하고자 합니다.
